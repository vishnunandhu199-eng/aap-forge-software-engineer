# App Forge Software Engineer Project

A starter software engineering project that combines Python, JavaScript, data structures and algorithms, SQL examples, and GitHub-ready project structure.

## What is included
- Python utilities for DSA and SQL examples
- JavaScript implementation of common algorithms
- CI workflow for Python and Node.js checks
- Simple starter files for GitHub-based portfolio work

## Project structure
- python/ - Python examples and utilities
- javascript/ - JavaScript algorithms and starter app
- .github/workflows/ - CI automation

## Quick start
1. Create a virtual environment:
   - python -m venv .venv
   - .venv\Scripts\activate
2. Install Python requirements:
   - pip install -r requirements.txt
3. Run the Python demo:
   - python python/app.py
4. Run the JavaScript demo:
   - node javascript/app.js

## Goals
- Practice Python and JavaScript together
- Build DSA problem-solving habits
- Learn SQL query patterns
- Prepare a clean GitHub project layout
